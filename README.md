# sistema-vendas-veiculos-sql
Projeto acadêmico de banco de dados relacional para gerenciamento de vendas de veículos
# Sistema de Vendas de Veículos

1. Visão geral

Este projeto acadêmico consiste no desenvolvimento de um banco de dados relacional para organizar informações sobre veículos, clientes, vendedores e vendas.

O objetivo é praticar a criação de tabelas, a definição de chaves primárias e estrangeiras e o relacionamento entre dados.

2. Tecnologias utilizadas

- MySQL
- SQL
- Banco de dados relacional

3. Estrutura do projeto

- `database.sql`: script SQL do projeto.
- `README.md`: documentação e instruções.
- `LICENSE`: licença do projeto.

4. Como executar

1. Instale o MySQL ou utilize um ambiente compatível.
2. Abra o MySQL Workbench ou outra ferramenta SQL.
3. Abra o arquivo `database.sql`.
4. Execute os comandos na ordem apresentada no arquivo.
5. Confira as tabelas e os dados criados.

5. Funcionalidades

- Cadastro e consulta de veículos.
- Organização de clientes e vendedores.
- Registro de vendas.
- Relacionamento entre as tabelas por meio de chaves estrangeiras.

*Observação: mantenha apenas as funcionalidades efetivamente implementadas no código.*
